OSI Model

Open Systems Interconnection — the 7-layer framework of networking

What is the OSI Model?

The OSI (Open Systems Interconnection) Model is a conceptual framework created by ISO that divides network communication into 7 layers. Each layer has a specific job, and together they describe how data travels from one device to another over a network.

The 7 Layers of OSI Model

Layer Name Function
7 Application Interacts directly with the user/software (e.g. browsers, email apps)
6 Presentation Formats, encrypts, and compresses data for the application layer
5 Session Establishes, manages, and ends communication sessions
4 Transport Ensures reliable data delivery (e.g. TCP, UDP)
3 Network Handles routing and logical addressing (IP addresses)
2 Data Link Handles physical addressing (MAC address) and error detection
1 Physical Transmits raw bits over cables, radio waves, or fiber
💡 Easy way to remember (top to bottom): "All People Seem To Need Data Processing" → Application, Presentation, Session, Transport, Network, Data Link, Physical.

Layer Details

7. Application Layer

The closest layer to the end user. It provides network services directly to applications like web browsers, email clients, and file transfer tools (protocols: HTTP, FTP, SMTP).

6. Presentation Layer

Also called the "translation layer". It converts data into a format the application layer can understand, and handles encryption, decryption, and compression.

5. Session Layer

Responsible for opening, maintaining, and closing sessions between two devices. It keeps track of whose turn it is to send data and helps resume interrupted sessions.

4. Transport Layer

Ensures data is delivered completely and in the correct order. TCP provides reliable, connection-based delivery, while UDP provides faster, connectionless delivery.

3. Network Layer

Responsible for routing data between devices across different networks using logical addresses (IP addresses) and determining the best path for data to travel.

2. Data Link Layer

Handles communication between devices on the same network using physical (MAC) addresses, and detects/corrects errors from the physical layer.

1. Physical Layer

The lowest layer, dealing with the actual physical connection — cables, switches, and signals (electrical, light, or radio) used to transmit raw bits of data.

Why is the OSI Model Important?

  • Helps understand how different networking protocols work together
  • Makes it easier to troubleshoot network problems by isolating the layer
  • Provides a standard reference used in networking education and certifications
  • Helps in designing and building interoperable network systems
